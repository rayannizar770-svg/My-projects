# ft_printf

## Description

**ft_printf** is a 42 core curriculum project that consists of recoding the standard C library function `printf()`. The goal is to build a static library, `libftprintf.a`, containing a custom `ft_printf()` function that mimics the behavior of the original `printf()`, including its return value (the number of characters printed).

Buffer management is not implemented — each conversion writes directly using the `write` system call. The function handles a defined subset of conversions: `c`, `s`, `p`, `d`, `i`, `u`, `x`, `X`, `%`.

## Algorithm and Data Structure

The core mechanism relies on C's **variadic functions**, provided through `<stdarg.h>` (`va_list`, `va_start`, `va_arg`, `va_end`). Since `ft_printf` can receive an unknown number of arguments of different types, these arguments have no fixed names and must be accessed sequentially through `va_arg`, which reads them in the exact order they were passed, using the type matching the conversion found in the format string.

The implementation is organized as follows:

- **`ft_printf`**: opens the `va_list` once with `va_start`, iterates over the format string character by character, and closes it once with `va_end` before returning. Every regular character is written directly; every `%` followed by a conversion character delegates to `ft_format`.
- **`ft_format`**: a dispatcher that receives the conversion character and the (already open) `va_list`, and calls the matching helper function (`ft_print_char`, `ft_print_str`, `ft_print_nbr`, `ft_print_unsigned`, `ft_print_hex_lower`, `ft_print_hex_upper`, `ft_print_ptr`) or handles `%%` directly.
- **One file per conversion**: each helper function is responsible for a single conversion. It pulls exactly one argument from the shared `va_list` with `va_arg`, using the C type expected for that conversion (accounting for default argument promotion, e.g. `char` is read as `int`), writes the result, and returns the number of characters it wrote.
- **Recursive number printing**: `%d`/`%i`, `%u`, `%x`/`%X` and `%p` each use a small recursive helper to print digits in the correct order (most significant digit first) without needing an intermediate buffer, mirroring the approach used for `ft_putnbr_fd` in libft.
- Signed values are converted to `long` before any sign manipulation, to safely handle `INT_MIN` without integer overflow.
- Every helper function returns the exact number of characters it printed, so `ft_printf` can accumulate and return the total character count, matching the original `printf()` behavior.

## Instructions

### Compilation

```bash
make          # builds libftprintf.a
make clean    # removes object files
make fclean   # removes object files and libftprintf.a
make re       # rebuilds from scratch
```

### Using the library

```c
#include "ft_printf.h"
```

```bash
cc -Wall -Wextra -Werror your_file.c -L. -lftprintf -o your_program
```

### Testing

Each conversion was checked against the original `printf()` by comparing both the printed output and the returned character count, including edge cases such as `NULL` strings, `NULL` pointers, `INT_MIN`, and large hexadecimal values.
