# libft

# Description

**libft** is the first low-level programming project of the 42 core curriculum. It consists of building a personal static C library, `libft.a`, re-implementing a set of standard C library functions from scratch and adding original utility functions, all under the 42 Norm coding standard.

# Instructions

## Compilation

```bash
make          # builds libft.a
make clean    # removes object files
make fclean   # removes object files and libft.a
make re       # rebuilds from scratch
```

```bash
cc -Wall -Wextra -Werror your_file.c -L. -lft -o your_program
```

## Using the library

```c
#include "libft.h"
```
## Testing

Each function was checked against its standard-library equivalent (where one exists) with a custom test file covering normal and edge cases (empty strings, `NULL`, boundary indexes, overlapping memory, ...).

## Additional Information

### Library  Overview

* **Standard Functions:** `isalpha`, `isdigit`, `isalnum`, `isascii`, `isprint`, `strlen`, `memset`, `bzero`, `memcpy`, `memmove`, `strlcpy`, `strlcat`, `toupper`, `tolower`, `strchr`, `strrchr`, `strncmp`, `memchr`, `memcmp`, `strnstr`, `atoi`, `calloc`, `strdup`.
* **Utility Functions:** `substr`, `strjoin`, `strtrim`, `split`, `itoa`, `strmapi`, `striteri`, `putchar_fd`, `putstr_fd`, `putendl_fd`, `putnbr_fd`.
* **Linked List Functions:** `lstnew`, `lstadd_front`, `lstsize`, `lstlast`, `lstadd_back`, `lstdelone`, `lstclear`, `lstiter`, `lstmap`.
